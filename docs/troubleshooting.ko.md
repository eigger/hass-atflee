# Bluetooth·측정 문제 해결

[English](troubleshooting.md) · [시작 페이지](../README.ko.md)

[Bluetooth 프록시 설정](https://github.com/eigger/hass-repo-standards/blob/main/docs/bluetooth.ko.md)을 먼저 확인하세요. XIAO W5500 V1.2(유선/PoE/외장 안테나)와 USB-A 동글 형태 M5Stack AtomS3U의 구매 링크·보드별 제약은 공통 문서에서 관리합니다. 이 추천은 새로운 Atflee 실물 검증을 의미하지 않습니다.

## 실패 단계부터 확인

체중계는 잠들면 보통 Bluetooth를 끕니다. 잠깐 밟아 깨우고 배터리를 확인하며 설정·측정 중 깨어 있게 하세요. 공식 Atflee/Fitdays 앱과 다른 BLE 클라이언트를 종료하세요. 휴대폰이 연결을 유지하면 페어링을 지웁니다. 이 통합은 계정·비밀번호·공통 본딩 키를 요구하지 않으며 미검증 모델의 인증 절차를 추측하지 않습니다.

광고 발견은 수신 확인일 뿐입니다. GATT에는 HA가 관리하는 연결 가능한 어댑터 또는 `bluetooth_proxy.active: true` 경로가 필요합니다. `esp32_ble_tracker.scan_parameters.active`는 scan response 요청 방식으로 역할이 다릅니다. interval/window는 우선 기본값을 유지합니다. 가까운 proxy를 이용할 수 있으며 정상 동작 중인 로컬 어댑터의 교체는 필수가 아닙니다.

| 증상·단계 | Atflee에서 확인할 내용 |
|---|---|
| 발견되지 않음 | 깨우기·proxy의 HA 온라인 상태·거리 확인. manifest 자동 발견은 `iGripX*`, 서비스 `0000ffb0-0000-1000-8000-00805f9b34fb`를 사용하므로 다른 모델은 추가 조사가 필요할 수 있습니다. |
| `connect` | 잠든 체중계의 연결 불가는 일반적입니다. 실제 측정 중 계속 실패하면 타 앱 점유·실제 어댑터/proxy 경로·전원/네트워크·빈 연결 슬롯을 확인합니다. |
| `arm` | 연결 후 측정 시작/사용자 정보 준비 단계 오류입니다. 키·생년월일·성별을 확인하고 모델·오류를 제보합니다. 스캔 설정을 반복 변경하지 않습니다. |
| `measure` | 연결 후 측정 패킷 처리 오류입니다. 오류와 비식별화한 재현 패킷을 남깁니다. 발견 실패와 구분합니다. |
| peer disconnect·링크 단절·쓰기 timeout | 체중계를 깨어 있게 하고 거리·배터리·proxy 전원/네트워크·동시 연결을 확인합니다. 경로 복구 후 재시도합니다. 쓰기 timeout과 측정 종료 후 정상 유휴 timeout은 다릅니다. |
| 사용자 체중이 기록되지 않음 | 한 명 이상 등록했는지, 활성/기본 사용자·기준 체중·허용 오차를 확인합니다. 미귀속 시 센서 갱신 대신 `atflee_unassigned_measurement` 이벤트가 발생할 수 있습니다. [사용자 식별](usage.ko.md#여러-사용자와-체중-식별)을 참고합니다. |
| 체성분 없음 | 프로필·지원 모델·체성분 스위치·실제 수신 패킷을 확인합니다. 값 수신 후에만 추가 지표가 생성됩니다. 연결 시 전송한 프로필과 최종 식별 사용자가 다를 수 있습니다. [상세](usage.ko.md). |
| 상태가 unknown/`other` | Measure Status의 코드 1만 `weighing`으로 알려져 있습니다. `raw`를 확인합니다. Verify/Scale Status는 의미가 알려지지 않아 새 entry는 기본 비활성입니다. 확인된 기기 오류로 해석하지 않습니다. |

## 실제 제공하는 진단 경로

**체중계 기기**의 **연결 시간(Connection Duration)** 속성에서 최근 종료 세션, **최근 실패(Last Failure)** 속성에서 최근 실패 세션, **실패 횟수(Failure Count)**를 확인합니다. 실행 중인 세션에서는 연결 시간 센서에 이전 종료 보고를 표시하지 않습니다. 존재하는 단계/detail·오류/원인·연결 경로·시간 정보를 확인하세요. 실제 연결 경로와 광고 최적 수신/미확인 경로를 구분합니다. 사용자 센서에는 해당 사용자의 측정 속성만 있고 최근 원시 패킷·연결 정보는 체중계 기기에 있습니다. 모델/펌웨어·전극 능력도 확인하세요. 별도의 통합 진단 다운로드 endpoint는 제공하지 않습니다.

필요한 재현 구간만 일시적으로 수집합니다.

```yaml
logger:
  default: warning
  logs:
    custom_components.atflee: debug
```

필요한 로그 재로드/재시작 후 깨어 있는 체중계에서 한 번 재현하고 디버그를 끄세요. 로그에 원시 패킷·Bluetooth 주소·프로필·측정값이 들어갈 수 있습니다. 공개 전 MAC/일련번호, 이름·생년월일·키·성별·체중/체성분, 이를 인코딩한 원시 payload, 내부 주소·인증정보를 제거합니다. 안전한 범위의 시각·단계/오류·모델/펌웨어는 보존합니다.

HA·통합·확인 가능한 blesession 버전, 체중계 모델/펌웨어, proxy 모델/리비전/펌웨어·로컬/Ethernet/Wi-Fi 경로, 실패 시각·깨우기 상태·다른 앱 연결·재현 절차·실패 단계와 비식별 로그를 제보합니다. 최근 성공과 실패, 자동 HA 테스트와 실물 검증을 구분하세요. BLE ESL 전용 Retry Count·Debounce 옵션은 없습니다.
